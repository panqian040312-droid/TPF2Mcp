## 七、环境坑清单（全部实测，别再踩）

- **Agent 工具侧**不能改写工作区外既有文件（`dangerouslyDisableSandbox` 也无效）；**用户双击 bat 可以**
- **robocopy 假报成功** → 必须回读目标文件长度/时间戳
- **bat 里 `(x86)` 的右括号会提前闭合 `if (...)` 块** → 用 `goto` 标签；`find /I "文本"` 在 chcp 936 下引号乱码 → 用 `findstr`
- `get_lines`（MCP）有 schema bug（返回数组声明成 record）→ 走 HTTP 接口
- `line.frequency_seconds` 不可信 → 用实测单圈时间
- **时钟比例随负载变**（0.43→1.07→4 倍速实测 1.7–2.1）→ 现读 `simulation.deltas`
- 引擎 tick 固定游戏时间（200ms/tick），**倍速不降模拟精度**
- 等待时长哨兵值：`request_time=0` 的实体等待=整个游戏时长（p90==max==同值即伪影）
- 「区间滞留」判据：`raw_state≠2 且门关且速度<5`（区分停站与堵在路上）
- 客运轨/货运轨由**车站站组**决定（`verify_station_binding.py` 验证）；**线路路径静态**，换轨只能靠路径牌（`check_direction.py` 测双向混跑）

## 八、TPF2 机制要点（实测得出）

- 相机角度**不向 Lua 暴露**（24 个 `game.interface.*` 方法、205 项 API 类型均无 camera）→ 地图自动跟随游戏视角**不可实现**
- 车辆 mod 的 `cameraConfig.positions` 是**车厢内司机视点**（静态数据），与自由视角无关
- 线路路径由引擎按最短路自动算，**玩家不能直接指定** → 强制走某条轨 = 停站序列里插路径牌（不停站的站点）
- 双线的正确用法是**按方向分**（一条东行一条西行，零交会）；按客货分（现状）会让每条都双向混跑
- `base_config.lua`（504 行）含产业密度/经济/需求灵敏度等**全部游戏参数**，且**可被 mod 覆盖**
- 货物定义在 `config/cargo_types/*.cargo.lua`（17 个）；地形高程图在 `config/terrain_heightmaps/*.png`（11 个）
