# TPF2 火车站 / 汽车站 / 码头 站场结构解析（2026-09-30）

> 与《TPF2_机场站场结构解析_20260930.md》**并列**：那份管机场，本份管另外三类站。**同名不同型，不要串台。**
> 目标一致：`slotId → 局部坐标 → 世界坐标`，公式还原自游戏本体 `.con`，再用真实存档的引擎包围盒验证。

---

## 零、一句话

三类站的 slotId **都编码了坐标信息**，公式全部从游戏本体 `.con` 读出并实测通过：

| 站型 | `.con` | slotId 与坐标的关系 |
|---|---|---|
| **火车站** | `station/rail/modular_station/modular_station.con` | `id = 基址 + 1000i + 10j` → 坐标 `(5i + 偏移, 40j, z)` |
| **汽车站** | `station/street/modular_terminal.con` | `id = 200000×(j+100) + 100×(i+100) + 变体` → 坐标由**累积布局**算 |
| **码头** | `station/water/harbor_modular.con` | `id = 1000000×(i+100) + 100×(j+100) + 朝向` → 坐标由**朝向表**算 |

**验证**（真实存档，三类站各一座）：推导锚点**全部落在引擎包围盒内**，残差**四个方向全 ≤ 0**
（引擎的框是模型包围盒，只会比槽位锚点更大）。

## 一、火车站

**出处**：`modular_station.con` 的 `GetId(type, subtype, i, j, k, o)` 与 `AddSlot`。

### 1.1 八个槽位基址

```
mainBuilding 3400000 · platform 4400000 · cargoPlatform 6400000 · passengerPlatform 7400000
track 8400000 · stairs 9400000 · passengerPlatformRoof 10400000 · passengerPlatformAddon 10800000
```

🔴 **只有这五个走 `基址 + 1000i + 10j`**：`cargoPlatform 6400000` / `passengerPlatform 7400000` /
`track 8400000` / `roof 10400000` / `addon 10800000`。
**主建筑 3400000 与楼梯 9400000 不是这个形式**（见 1.3），若混进同一套反解会**把主建筑抢先把匹配成站台、坐标全错**。

### 1.2 坐标公式

```
platformWidth = 5    platformLength = 40    j ∈ [jMin, jMax] = [-10, 10]
AddSlot(i, j, 基址, 类型, 偏移, …)：
    id    = 基址 + 1000×i + 10×j
    transf= 平移(5×i + 偏移, 40×j, z)
```

| 类型 | 基址 | 偏移 | z |
|---|---|---|---|
| 客运站台 `passenger_platform` | 7400000 | 0 | 0 |
| 轨道 `track` | 8400000 | 0 | 0 |
| 货运站台 `cargo_platform` | 6400000 | **+2.5**（`platformWidth/2`） | 0 |
| 站台顶棚 `roof` | 10400000 | 0 | **2** |
| 通道加装 `addon` | 10800000 | 0 | **2** |
| 楼梯 `stairs` | 9400000 | 见 1.3 | 0 |

> 站台与轨道**共用同一 (i,j) 格**（偏移都是 0）——锚点重合，靠模块自身的模型错开。

### 1.3 主建筑与楼梯（**不吃 `1000i+10j`**）

```
主建筑（updateFn）：id = 3400000 + 3000×i + 40×j + 10×k + o     o ∈ {0,1,5,6,7}
   · o=0/1 → 主楼本体；o=5/6/7 → 侧楼（size1/2/3）
   · i = minS[j]（回侧）→ x = -10 − minS[j]×5          「回侧」= throughBackTag，偏移 0
   · i = maxS[j]（前侧）→ x = -10 − (maxS[j]×5 − 20)    「前侧」= throughFrontTag，偏移 +200000
   · y = j×40 + k×10
楼梯：id = 9400000 + 10×j + {0,1}
   · +1 → (maxS[j]×5 + 2.5, j×40)   · +0 → (minS[j]×5 − 2.5, j×40)
```

`minS[j]` / `maxS[j]` = 该排 j 上**站台列 i 的最小/最大值**，可直接从站台槽位 id 反推，不必重建整个布局。

### 1.4 实测（station 104459）

68 个槽位：客运站台 18 · 轨道 24 · 顶棚 12 · 通道加装 9 · 主建筑/侧楼 5。
站台在第 i = 0/3/6 列（x = 0/15/30 m），轨道在 i = 1…5 列，j 排 −2…3（y = −80…120 m）。
该站整体旋转 **−90°**，所以「沿轨道方向」对应世界的 X 轴。

| 轴 | 推导锚点 | 引擎包围盒 | 残差 |
|---|---|---|---|
| x | −1602.6 … −1402.6 | −1632.6 … −1372.6 | **+30.0 / −30.0** |
| y | −1613.0 … −1573.0 | −1628.5 … −1570.3 | **+15.5 / −2.7** |

## 二、汽车站 / 卡车货运站

**出处**：`modular_terminal.con` 的 `MangleId` / `DemangleId` 与 `coordI2varaintAndPos` 布局循环。

### 2.1 slotId 编解码

```lua
MangleId({i, j, v})   = 200000×(j+100) + 100×(i+100) + v
DemangleId(id)        →  v = id % 100;  t=(id−v)/100;  i = t%2000 − 100;  j = t/2000 − 100
```

**变体号 `v` 是必要条件**（`modular_terminal.con:1283`）：

| v | 含义 | v | 含义 |
|---|---|---|---|
| 0 | 客运站台 | 5 | 出口 |
| 1 | 货运站台 | 6 / 7 / 8 | 竖向出入口（组合/入口/出口） |
| 2 | 小建筑 | 9 | 大建筑 |
| 3 | 出入口（双向） | 4 | 入口 |

### 2.2 坐标：**横向位置是累积算出来的**（这是本类站唯一的难点）

站台列沿 x 排开，每列的 x = 上一列 x ± (轨道 5 m + 前半宽 + 后半宽)：

```
centerSize = 20   trackSize = 5   客运站台宽 5   货运站台宽 10
右侧（i ≥ 0）：loc = 10；last = −5
   每列： loc += 5 + last ;  last = 该列半宽(客运 2.5 / 货运 5) ;  loc += last
左侧（i ≤ −1）：loc = −10；last = −5，同样对称地往负方向推
模块坐标 = (该列 x, j × 10, 0)          ← 纵向 10 m 一格
```
⇒ **要算某一列的 x，必须先知道从 i=0（或 −1）到它之间每一列是客运还是货运**。
判据：该列在 `j=0` 处有没有 `v=0`（客运）的模块。

**出入口（`i = 55` 哨兵值）**：底侧 `(0, minPos×10 − 15)`、顶侧 `(0, maxPos×10 + 15)` 且朝向 180°。
非哨兵列上的出入口则是 `(该列 x ± 偏移, 同 y)`，偏移 = 客运 2.5 / 货运 5。

### 2.3 实测（station 128024）

5 个槽位，全是 `v=1` **货运站台** + 1 个出入口。布局解出 `rightLen=0, leftLen=−1`，
两列 x = **+15 / −15**（都是货运列，半宽 5），y = 0 与 10；
出入口在 `(0, −15)`（minPos=0）。

| 轴 | 推导锚点 | 引擎包围盒 | 残差 |
|---|---|---|---|
| x | 5033.5 … 5062.7 | 5018.6 … 5076.7 | **+14.9 / −14.1** |
| y | −5716.7 … −5685.9 | −5726.6 … −5675.9 | **+10.0 / −10.0** |

## 三、码头

**出处**：`harbor_modular.con` 的 `MangleId` / `DemangleId` 与 `slotDef` 表 + `AddSlot`。

### 3.1 slotId 编解码

```lua
MangleId({i, j, facing}) = 1000000×(i+100) + 100×(j+100) + facing
DemangleId(id)           →  facing = id % 100;  t=(id−facing)/100
                            j = t % 10000;  i = t/10000;  最后都 −100
```

### 3.2 朝向 `facing` 决定一切

`slotDef` 表按 `facing` 分段（每段 4 个朝向：下 / 右 / 上 / 左）：

| 段 | `facing` | 模块 | 备注 |
|---|---|---|---|
| `50_12` | 0–3 | `water_module_50_12` | |
| `50_12_flip` | 4–7 | `water_module_50_12` | |
| `100_25` | 8–11 | `water_module_100_25` | |
| `100_25_flip` | 12–15 | `water_module_100_25` | |
| `100_50` / `_flip` | 16–23 | `water_module_100_50` | |
| `50_50` / `_flip` | 24–31 | `water_module_50_50` | |
| **未翻转栈桥** | **32–35 / 40–43** | — | ⚠️ **`.con` 里被注释掉 → 该 `facing` 没有槽位** |
| `50_12_pier` | 36–39 | `water_pier_50_12` | |
| `100_12_pier` | 44–47 | `water_pier_100_12` | |
| `12_12` | 48–51 | `pedestrian_entrance` | |

坐标（`gridSize = 12.5`，`t = facing % 4 + 1`）：

```lua
off = offset[t]   shf = shift[t]
t == 1 或 3 → pos = ((i+0.5)×12.5 + shf, (j+0.5)×12.5 + off×0.5)
否则        → pos = ((i+0.5)×12.5 + off×0.5, (j+0.5)×12.5 + shf)
朝向 = angle[t]
```

🔴 **`offset` / `shift` 是「带正负号的四元素数组」，不是一个标量**：
`offset = {+k, −k, −k, +k} × 12.5`、`shift = {−0.5, −0.5, −0.5, −0.5} × 12.5`（`50_12` 与 `12_12` 的 shift 为 0）。
**按标量存会把坐标整体偏 12.5 m**（本次实测踩过，见第五节）。

### 3.3 实测（station 102164）

7 个槽位：`water_pier_100_12` ×1 · `water_module_100_25` ×1 · `water_module_50_50` ×1 ·
`pedestrian_entrance` ×4（在同一排 j=1 上横向排开，i = −2…1）。

| 轴 | 推导锚点 | 引擎包围盒 | 残差 |
|---|---|---|---|
| x | −4401.6 … −4364.1 | −4436.8 … −4335.2 | **+35.3 / −28.9** |
| y | −2859.7 … −2778.3 | −2871.2 … −2767.9 | **+11.5 / −10.4** |

## 五、三个坑（都踩过）

1. 🔴 **火车站：主建筑 id 也落在 3400000 基址上，会被站台反解抢先匹配。**
   `3400020` 既像「主楼（j=0,k=2）」又像「站台（i=0,j=2）」。判据：**主建筑从不用 `1000i+10j` 形式**
   （它是 `3000i+40j+10k+o`）⇒ 反解时**必须先把 `3400000` / `9400000` 从 `1000i+10j` 的基址表里剔出去**。
2. 🔴 **码头：`offset`/`shift` 是四元素带符号数组。** 写成标量会让 x 整体偏 12.5 m（正好一个网格）。
   验证时残差仍可能是负的（偏得不够大），**只看"是否越界"抓不住**，要对齐到网格再核。
3. 🔴 **汽车站：x 是累积量，不能单看 slotId 算。** 必须复现 `coordI2varaintAndPos` 的循环，
   并且**逐列判客运/货运**（判据 = 该列 j=0 处有没有 `v=0` 模块）。
